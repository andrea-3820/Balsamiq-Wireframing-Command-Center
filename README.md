## Features

- Ready-to-use wireframe templates for web, mobile and desktop applications
- Sketch-style UI component libraries for rapid low-fidelity prototyping
- Annotation and callout configuration guides for stakeholder feedback
- Interactive linking and navigation workflow examples
- Design review and collaboration templates for UX teams
- Export and presentation presets for client and developer handoff
- Step-by-step tutorials covering symbols, masters and reusable components
- Real-world examples demonstrating efficient wireframing and prototyping workflows

## Requirements

- Windows 10/11
- Installed Balsamiq (Desktop) or active Balsamiq Cloud account

## Usage

Open the extracted folder and explore the template and guide directories. Import the included wireframe templates and component libraries directly into Balsamiq or follow the documentation to configure annotations, linking, masters and exports. The guides provide practical instructions for each resource.

## About

This repository contains a comprehensive set of tools, templates and educational materials designed to improve wireframing, low-fidelity prototyping and UX collaboration workflows in Balsamiq.
